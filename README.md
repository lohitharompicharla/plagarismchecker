# plagarismchecker
# Plagiarism Checker and Document Analyzer Using GUI
##  Features

-  Load and analyze multiple .txt documents.
-  Calculate document similarity using *TF-IDF* and *Cosine Similarity*.
-  Visualize results with *heatmaps, **bar charts, and **word clouds*.
-  Perform *Sentiment Analysis* (positive, negative, neutral) using *NLTK VADER*.
-  Detect plagiarism based on a threshold (default: 0.8).
-  Export similarity results to .csv format.
-  Simple and intuitive GUI built with *Tkinter*
